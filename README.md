## Selected Projects

**[context-core](https://github.com/OscarLeal7/context-core)**
Personal context server that observes developer workflows, git activity, and system state to build a real-time model, exposed through an open WebSocket API.
`TypeScript` · `Node.js` · `GCP Pub/Sub` · `pgvector` · `WebSocket`

**[adaptive-os](https://github.com/OscarLeal7/adaptive-os)**
Autonomous personal operating layer that consumes context-core and takes agentic actions on the user's behalf, improving through ongoing feedback.
`TypeScript` · `Node.js` · `Claude API` · `pgvector` · `Graph API`

**[dungeon-engine](https://github.com/OscarLeal7/dungeon-engine)**
Text-based RPG engine using Claude as narrator, with persistent world state, long-term memory via RAG, and a rules engine that governs multiplayer logic.
`TypeScript` · `Node.js` · `Claude API` · `Supabase` · `WebSocket`

## Engineering Principles

- **Security by design** — access control enforced at the database layer, not the application layer
- **Deterministic financial logic** — reconciliations and calculations that are exact, transparent, and auditable
- **AI as infrastructure** — language models and vector search treated as backend services with memory and feedback loops
- **Resilience** — progressive web apps, local caching, and real-time updates with graceful degradation
